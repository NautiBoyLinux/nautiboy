# NautiBoy v0.1.0 release notes

NautiBoy v0.1.0 is the first hardware-validated static-image release. It can
discover a supported CORSAIR Nautilus LCD Cap, show firmware identity, prepare
JPEG or PNG images as 480×480 baseline JPEGs, and maintain one selected image
using bounded volatile refreshes. Closing the application restores the existing
hardware-mode display.

The release was physically validated on `1b1c:0c57`, interface 0, firmware
0.3.0.5, using Fedora KDE Plasma 44. Other distributions and firmware versions
remain unverified.

This release intentionally excludes GIF playback, monitoring screens, profiles,
persistent storage, brightness, rotation, RGB, firmware updates, and pump or fan
control.

NautiBoy is an unofficial community project and is not affiliated with, endorsed
by, or supported by Corsair.
